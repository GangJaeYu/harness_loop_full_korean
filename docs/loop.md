# 개발 루프

[← README](../README.md)

`loop-setup`이 `loop_setup/LOOP.md`에 실행 방식을 정하고, Loop 시작이 승인되면 구현·검증·복구·최종 보고까지 진행합니다. 운영을 바꿀 때는 `loop-update`를 씁니다.

## Loop가 하는 일

1. 의존이 풀린 태스크를 고릅니다. 서로 독립이면 동시에 배정합니다.
2. 워커가 구현하고 `lint → unit → e2e`를 통과시킵니다.
3. 구현하지 않은 별도 세션이 `task_validation`으로 수용 기준을 직접 확인합니다.
4. 결과를 통합하고, 통합 뒤의 영향 검사를 다시 돌립니다.
5. 모두 끝나면 완료 범위·증거·남은 미검증을 보고합니다. 못 끝낸 것은 이유와 재개 조건을 남깁니다.

진행 상황은 `plan_setup/STATE.md`(지금 어디인지)와 `plan_setup/LOG.md`(무슨 일이 있었는지)에 남습니다. STATE는 갑자기 끊겨도 원래 대화 없이 이어 갈 수 있게, 진행 중인 워커·작업 위치·아직 반영 안 된 결과·다음 행동을 담고 상태가 바뀌는 커밋마다 함께 갱신됩니다.

## 병렬

독립 작업은 병렬이 기본입니다. 워커 수는 에이전트가 정합니다. 기준은 의존 관계, 같은 파일·DB·포트·앱을 건드리는지, 가용 자원입니다.

- 공유 상태(STATE·LOG·통합)를 고치는 쪽은 하나로 둡니다.
- 동시에 코드를 바꾸는 워커는 서로의 미완성 변경이 섞이지 않는 위치(별도 워크트리 등)에서 작업합니다. 별도 작업 사본에는 커밋 안 된 문서가 없을 수 있으므로, 문서의 정본 위치를 알려 줍니다.
- 무거운 빌드·브라우저·컨테이너는 워커 수와 별도로 동시 실행 수를 제한합니다. 필요하면 1개로 줄입니다.

### Orca에서 병렬로 돌리기

Orca가 있으면 워크트리별 워커로 나눠 실행합니다. 이름 규칙은 아래와 같습니다.

| 역할 | 이름 |
|---|---|
| 구현 워커 | `phase-01-task-02-worker` |
| 검증 워커 | `phase-01-task-02-validation-worker` |
| 조정자 | `phase-01-coordinator` (여러 phase면 `phase-01-03-coordinator`) |

Orca로 띄운 Claude 워커는 권한 확인 없이 실행됩니다. 허용 범위는 Loop 전 합의에 분명히 적어 두세요.
Orca가 없으면 호스트의 서브에이전트나 별도 CLI 세션을 씁니다.

## 실패와 전략 전환

실패하면 먼저 원인을 가립니다. 코드 결함, 검사와 문서의 불일치, 환경 문제, 흔들리는 테스트 중 무엇인지 봅니다.

- 같은 방식의 수정이 **3번 안에** 풀리지 않으면 멈추지 않고 심층 분석으로 넘어갑니다. 실패 관찰·가설·결과를 대조해 다른 전략을 씁니다.
- 검사를 약하게 만들거나 같은 조치의 이름만 바꾼 것은 새 전략으로 치지 않습니다.
- 시도 이력과 전체 예산은 세션이 바뀌어도 초기화하지 않습니다.
- 예산이 다 됐거나, 필요한 권한이 없고 대안도 없으면 독립 작업만 마칩니다. 그 뒤 변경·증거·재개 조건을 남기고 **미완료로 보고**합니다. 질문을 남겨 놓고 기다리며 끝내지 않습니다.

## 모델과 사용량 한도

Loop 전에 역할별(조정·구현·검증) 기본 모델과, 사용량 한도에 걸렸을 때 어떻게 할지를 정합니다.

- 기다렸다가 재개
- 허용한 다른 모델로 대체
- 그 지점에서 중단하고 재개 지점 기록

실제로 쓴 모델과 대체 여부는 LOOP.md에 기록합니다. 정하지 않은 모델로 조용히 바꾸지 않습니다.

## 중단과 재개

- 자동 재시작을 합의하지 않았다면 **부모(조정) 세션이 끊기면 Loop도 멈춥니다.** 이미 돌던 워커는 맡은 일을 마칠 수 있지만, 새 배정은 없습니다.
- 다시 부르면("이어서 진행해줘") 새 세션이 LOOP·STATE·LOG를 실제 코드·커밋 안 된 변경·살아 있는 워커와 대조해 다음 행동부터 이어 갑니다. 끝난 작업을 다시 구현하거나, 살아 있는 작업을 중복으로 띄우지 않습니다.
- 예산이 시각으로 정해져 있으면, 오래 지나 재개할 때는 새 예산을 함께 주세요.
- 직접 멈추고 싶으면 그냥 세션을 멈추면 됩니다. 별도 정지 명령은 없습니다.
