# Codex에서 루프 실행

현재 실행 환경이 Codex일 때만 읽는다.

- 도구 목록에서 셸·브라우저·서브에이전트·앱 기능과 현재 권한을 확인한다.
- 현재 세션으로 충분하면 이어 실행한다. 자동 호출이 없으면 필요한 스킬 지침을 읽어 직접 수행한다.
- CLI를 쓸 때는 `codex exec --help`로 작업 폴더·출력·승인/샌드박스·재개 옵션을 확인한다.
- 구현·재개 자식은 해당 폴더의 `AGENTS.md`와 LOOP·STATE를 읽는다. task_validation에는 본문의 최소 운영 인계만 주고 STATE·LOG 전체는 제외한다.
- 모델·동시 수·사용량은 기존 합의와 남은 전체 예산 안에서 운용한다.
- 부모의 도구·브라우저·권한이 자식에도 있다고 가정하지 않는다.
- 지시문 제출·실행 시작·완전한 결과 수신을 실제 상태로 확인한다.
- 승인이 거부되면 우회 옵션을 켜지 않고 허용된 대안을 사용한다.
- 실행을 끝내려면 실제 수용 기준을 검사하고 미완료·재개 조건까지 기록한다.

- Codex 서브에이전트/exec의 실제 대화 상속·재개 동작을 확인해 task_validation에는 구현 이력이 없는 실행을 사용한다.
