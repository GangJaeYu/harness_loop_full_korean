# Codex에서 하네스 준비

현재 Codex로 실행할 때만 이 차이를 확인한다.

- 현재 노출된 셸·브라우저·서브에이전트·앱 도구와 승인/샌드박스 범위를 확인한다.
- UI의 선택지 입력이나 자동 스킬 호출 여부는 실제 도구 목록으로 판단한다.
- 기존 패키지 명령·테스트 설정을 먼저 읽고 현재 셸에서 실행 가능한지 확인한다.
- 브라우저 연결이 없으면 설치된 E2E 실행 수단으로 화면 기준을 검사한다.
- 제품 task_validation 경로를 준비할 때 현재 제공된 서브에이전트나 CLI 실행 수단을 확인한다.
- CLI를 사용할 때만 `codex exec --help`로 작업 폴더·출력·권한 옵션을 확인한다.
- 자식 실행은 해당 폴더의 `AGENTS.md`와 하네스 위치를 읽도록 연결한다.
- 부모 도구와 브라우저 연결을 자식이 그대로 쓸 수 있다고 가정하지 않는다.
- 지원되지 않는 기능은 실제 대안으로 처리하고 권한 거부를 우회하지 않는다.

- Codex 서브에이전트/exec의 실제 대화 상속·재개 동작을 확인해 task_validation에는 구현 이력이 없는 실행을 사용한다.
