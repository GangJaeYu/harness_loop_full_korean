# Codex에서 하네스 갱신

현재 호스트의 실행 차이가 갱신 원인일 때만 읽는다.

- 실제 셸·브라우저·서브에이전트 도구와 승인/샌드박스 범위를 확인한다.
- 기존 `AGENTS.md`·하네스 포인터와 변경 대상 설정을 읽는다.
- CLI를 사용 중이면 `codex exec --help`로 현재 작업 폴더·출력 옵션을 확인한다.
- 셸/OS가 바뀌었으면 실제 스크립트의 인코딩·인수 전달을 확인한다.
- 부모와 자식의 관찰 수단·권한 차이를 실행 증거로 확인한다.
- 중단된 명령은 남아 있는 실행과 결과를 확인한 뒤 재개한다.
- 권한 거부를 없애려고 승인·샌드박스를 넓히지 않는다.
- UI·자동 호출의 유무는 제품명 대신 현재 도구로 판단한다.
- 변경한 관찰 경로를 실행하고 미검증 범위를 분리해 기록한다.

- Codex 서브에이전트/exec의 실제 대화 상속·재개 동작을 확인해 task_validation에는 구현 이력이 없는 실행을 사용한다.
