# Claude Code에서 하네스 갱신

현재 호스트의 실행 차이가 갱신 원인일 때만 읽는다.

- Read·검색·셸 도구의 현재 이름과 권한을 확인한다.
- 기존 프로젝트 명령과 변경 diff를 읽고 영향 있는 설정만 수정한다.
- 실행 셸과 CLI 버전이 바뀌었으면 도움말로 실제 옵션을 확인한다.
- 자식 검증이 있다면 그 작업 폴더의 `CLAUDE.md`와 사용 가능한 관찰 수단을 확인한다.
- 부모에서 가능한 브라우저 조작이 자식에서도 가능한지 실제로 확인한다.
- 검증 출력이 잘리거나 실행이 끊겼으면 프로세스와 원본 결과를 확인한다.
- 도구 대기 시간과 제품 실패를 혼동하지 않는다.
- 권한 거부는 합의된 대안이나 최종 미완료로 처리한다.
- 수정한 명령을 현재 셸에서 돌리고 실행하지 못한 범위를 보고한다.

- Claude Agent/CLI의 실제 대화 상속·재개 동작을 확인해 task_validation에는 구현 이력이 없는 실행을 사용한다. Agent `fork`는 부모 대화를 상속하므로 쓰지 않고 `general-purpose` 등 새 Agent나 새 `claude -p`(`--resume`·`--continue` 없이)를 쓴다.
