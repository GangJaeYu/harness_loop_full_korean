# Codex 환경 참고 — trd-generator

- 현재 세션의 파일·셸·질문·브라우저·서브에이전트 도구와 권한을 확인한다.
- Codex라는 이름만으로 선택지 UI·자동 호출·서브에이전트가 없다고 단정하지 않는다.
- 질문 도구가 제공되면 필요한 사전 결정에 사용하고 없으면 선택지와 영향을 짧은 평문으로 제시한다.
- 이미 합의한 답은 다시 묻지 않는다. 질문 가능 여부와 실제 사용자 권한을 구분한다.
- 제공된 파일 수정 도구를 사용하고 셸을 쓰면 현재 OS와 인용 규칙을 확인한다.
- 한국어 문서는 UTF-8로 쓰고 수정 후 파일·YAML·링크가 유지됐는지 읽어 확인한다.
- 사용자가 진행을 확인한 다음 스킬은 호출 기능이 있으면 사용하고, 없으면 SKILL.md를 읽어 같은 세션에서 계속한다. 확인 전이면 SKILL.md대로 결과를 보고하고 진행 여부를 묻는다.
- 서브에이전트·CLI는 실제 기능과 실행 허용 범위를 확인하고 필요할 때만 쓴다.
- Orca 안에서는 해당 CLI 도움말/스킬로 실제 기능을 확인한다. 새 운용 플랫폼을 만들 필요는 없다.
- 도구 권한을 우회하지 않는다. 운영 합의·차단 처리·완료 기준은 본문과 프로젝트 문서를 따른다.
- 실제 실행하지 못한 검증은 미검증으로 보고한다.
