# Claude Code 환경 참고 — trd-generator

- 세션에 노출된 도구와 권한을 먼저 확인한다. 설치/버전에 따라 사용 가능 기능이 다르다.
- Read·Glob·Grep이 있으면 입력과 관련 코드 조사에 사용한다. 없으면 허용된 파일/셸 도구를 쓴다.
- Write/Edit가 있으면 신규 작성과 부분 수정을 구분한다. 수정 후 실제 파일을 다시 읽는다.
- AskUserQuestion이 제공되면 필요한 사전 결정을 묶어 묻는다. 미제공이면 짧은 평문으로 묻는다.
- 이미 확정된 답은 문서에서 재사용한다. 도구 UI를 쓰기 위해 질문을 새로 만들지 않는다.
- 사용자가 진행을 확인한 다음 스킬은 Skill 호출이 가능하면 호출한다. 확인 전이면 SKILL.md대로 결과를 보고하고 진행 여부를 묻는다. 없으면 해당 SKILL.md를 읽고 계속 수행한다.
- 서브에이전트 도구의 실제 제공 여부와 실행 권한을 확인하고 본문·프로젝트의 운용 합의를 따른다.
- Mermaid/브라우저 검증 도구가 있으면 실제 실행하고 없으면 미검증 범위를 밝힌다.
- 운영 합의와 완료 기준은 본문 및 프로젝트 문서가 정한다. 이 참고가 추가 승인 절차를 만들지 않는다.
- 실행 요청은 도구 전환 안내만 남기고 끝내지 않는다.
