# Claude Code 환경 참고 — code-to-docs

현재 세션에 노출된 도구와 권한을 먼저 확인한다.
파일 조사는 Read·Glob·Grep, 실행은 제공되는 셸 도구를 사용할 수 있다.
프로젝트 지침은 `CLAUDE.md`와 실제 적용되는 상위 지침을 읽는다.
Skill 도구가 있으면 필요한 스킬을 호출할 수 있다.
없으면 해당 `SKILL.md`를 읽고 같은 세션에서 필요한 절차를 수행한다.
Agent/Explore 도구는 실제 제공 여부와 현재 지시의 허용 범위를 확인한다.
독립 조사/검토에 이득이 있을 때만 사용하고 완료 증거를 직접 확인한다.
문서 근거는 검색 결과의 파일·줄과 실행 관찰을 연결한다.
브라우저 관찰은 연결된 브라우저 도구나 설치된 실행 수단을 확인해 쓴다.
셸 구문·경로는 실제 OS에 맞추고 프로젝트의 기존 명령을 우선한다.
도구가 막은 권한을 우회하거나 미실행을 성공으로 기록하지 않는다.
