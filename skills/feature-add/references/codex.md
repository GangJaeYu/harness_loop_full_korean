# Codex 환경 참고 — feature-add

현재 세션의 도구 목록·권한·셸·작업 경로를 먼저 확인한다.
프로젝트 지침은 `AGENTS.md`와 실제 적용되는 상위 지침을 읽는다.
파일 검색은 `rg --files`·`rg -n`을 우선하고 없으면 제공 도구를 쓴다.
스킬 호출 수단이 있으면 필요한 스킬을 호출한다.
없으면 해당 `SKILL.md`를 읽고 같은 세션에서 절차를 이어 수행한다.
서브에이전트·CLI 자식 실행은 현재 노출된 기능과 사용자 지시로 판단한다.
Codex라는 이름만으로 UI·서브에이전트·자동 호출이 불가능하다고 단정하지 않는다.
기존 ID와 추가 절 번호는 파일 검색으로 확인하고 필요한 절차만 연결한다.
화면 검증은 연결 브라우저나 설치된 도구를 확인해 실행한다.
PowerShell/Bash 구문은 실제 셸에 맞추고 기존 프로젝트 명령을 우선한다.
권한 거절은 증거로 남기고 허용된 대안 또는 미완료 처리로 마친다.
