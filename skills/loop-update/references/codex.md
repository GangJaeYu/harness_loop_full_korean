# Codex에서 루프 갱신

현재 Codex 실행 수단을 바꿀 때만 읽는다.

- 실제 도구 목록과 현재 승인/샌드박스 범위를 확인한다.
- CLI가 관련되면 `codex exec --help`로 현재 작업 폴더·출력·재개 옵션을 읽는다.
- 구현·재개 자식의 `AGENTS.md`와 LOOP·STATE 연결을 점검한다. task_validation에는 본문의 최소 운영 인계만 주고 STATE·LOG 전체는 제외한다.
- 서브에이전트·UI·자동 스킬 호출은 노출된 기능으로 판단한다.
- 기존 실행 주체와 미반영 결과를 확인한 뒤 운영 변경을 적용한다.
- 입력 초안·실행 중·중단·완료는 실제 상태와 결과로 구분한다.
- 모델·동시 수를 바꿔도 기존 전체 예산과 사용량 이력을 이어받는다.
- 권한 거부는 허용된 대안으로 처리하고 승인 범위를 임의로 넓히지 않는다.
- 변경한 재개 경로를 실제로 확인하고 원래 요청의 검증까지 이어 간다.

- Codex 서브에이전트/exec의 실제 대화 상속·재개 동작을 확인해 task_validation에는 구현 이력이 없는 실행을 사용한다.
