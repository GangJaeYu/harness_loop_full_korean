# Claude Code에서 루프 갱신

현재 Claude Code 실행 수단을 바꿀 때만 읽는다.

- 노출된 Agent·브라우저·셸 기능과 사용 중인 CLI의 도움말을 확인한다.
- 구현·재개 자식의 작업 폴더·`CLAUDE.md`·LOOP·STATE 연결을 점검한다. task_validation에는 본문의 최소 운영 인계만 주고 STATE·LOG 전체는 제외한다.
- 실행 중인 주체와 미반영 결과를 확인한 뒤 안전한 경계에서 운영을 바꾼다.
- 백그라운드 명령의 도구 대기와 실제 종료를 구분한다.
- 모델/허용 도구/예산 옵션은 현재 버전과 기존 합의 안에서만 조정한다.
- 부모와 자식의 브라우저 연결·권한 차이는 실제 관찰로 확인한다.
- 새 실행 주체를 띄우기 전에 기존 실행과 상태 필자를 확인한다.
- 현재 기능으로 충분하면 새 구동 스크립트를 만들지 않는다.
- 갱신 뒤 실제 재개와 검증을 확인하고 미검증 한계를 기록한다.

- Claude Agent/CLI의 실제 대화 상속·재개 동작을 확인해 task_validation에는 구현 이력이 없는 실행을 사용한다. Agent `fork`는 부모 대화를 상속하므로 쓰지 않고 `general-purpose` 등 새 Agent나 새 `claude -p`(`--resume`·`--continue` 없이)를 쓴다.
