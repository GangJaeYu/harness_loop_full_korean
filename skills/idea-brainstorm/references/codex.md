# Codex 환경 보조 지침 (idea-brainstorm)

## 선택지 질문은 평문 번호 목록으로

Codex에는 선택지 UI 도구가 없으므로 질문을 그대로 텍스트로 쓴다. 사용자가 짧게 답할 수 있는 형태가 중요하다.

- 한 번에 1~2개 질문만 보낸다. 목록이 길면 사용자는 답을 건너뛴다.
- 선택지는 `A) … B) … C) 기타(직접 입력)` 형태로 쓰고, 각 선택지 뒤에 그 선택의 결과를 한 줄로 붙인다.
- 답을 짧게 받을 수 있도록 마지막에 회신 형식을 알려준다. 예: `→ "1-B, 2-A" 처럼 답해 주셔도 됩니다.`
- 사용자가 여러 질문에 한꺼번에 답하면, 다음 메시지 첫머리에 이해한 내용을 한 줄씩 되짚어 확인한다.
  선택지 UI가 없는 환경에서는 오해가 조용히 누적되기 쉽다.

## 파일 작성

`docs/IDEA.md` 는 파일 쓰기 도구(또는 셸의 heredoc)로 만든다. 상대 경로 대신 프로젝트 루트 기준 경로를 쓴다.
승인 모드에 따라 파일 쓰기 권한 요청이 필요할 수 있으므로, 작성 직전에 "이 경로에 파일을 만들겠습니다"라고 알린다.

## 다음 스킬 연결

Codex에서는 스킬 자동 호출을 기대하지 말고, 다음 단계 안내를 명시적으로 남긴다.
예: `다음 단계: prd-generator 스킬(SKILL.md)을 읽고 docs/IDEA.md 를 입력으로 PRD를 작성합니다.`
