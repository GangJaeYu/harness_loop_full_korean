# Claude Code 환경 보조 지침 (idea-brainstorm)

## 선택지 질문은 AskUserQuestion 도구로

선택지가 2~4개로 정리되는 질문(타깃 사용자, MVP 범위, 방향 A/B/C 선택 등)은 텍스트로 나열하지 말고
`AskUserQuestion` 도구를 쓴다. 사용자가 클릭 한 번으로 답할 수 있고, "기타"로 자유 입력도 가능해서
답변률과 답변의 구체성이 눈에 띄게 좋아진다.

- `header`: 12자 이내 축 이름 (예: `타깃 사용자`, `MVP 범위`, `제품 방향`)
- 각 `option.description`에 **그 선택의 결과**를 적는다. ("이 경우 결제·정산 기능이 MVP에 들어옵니다.")
- 추천안이 있으면 첫 번째에 두고 라벨 끝에 `(추천)`을 붙인다.
- 4단계의 방향 A/B/C 비교처럼 안끼리 눈으로 비교해야 하는 경우에는 `preview`에 각 안의 요약 블록을 넣는다.
- 여러 축을 동시에 물어도 되는 상황이면 한 번의 호출에 질문을 최대 4개까지 묶는다. 다만 서로 의존하는 질문
  (앞의 답에 따라 뒤 질문이 달라지는 경우)은 묶지 말고 순차로 묻는다.

자유 서술이 필요한 질문(문제 상황을 겪은 장면, 성공 기준의 숫자 등)은 도구 대신 평문으로 묻는다.
객관식으로 강제하면 오히려 정보가 줄어든다.

## 파일 작성

`docs/IDEA.md` 는 Write 도구로 만든다. 디렉터리가 없으면 먼저 만든다.
기존 파일이 있으면 덮어쓰기 전에 반드시 읽고, 사용자에게 갱신할지 새로 만들지 확인한다.
